# Real-Time Object Detection in Autonomous UAVs using YOLO and OpenCV

Welcome to my presentation page for this term. My presentation focuses on integrating **YOLO (You Only Look Once)** and **OpenCV** to perform real-time object detection and tracking in Unmanned Aerial Vehicles (UAVs).

---

### Key Highlights
- **Real-Time Detection:** Processing live video feeds with minimal latency on embedded systems.
- **Autonomous Navigation:** Using bounding box coordinates to guide autonomous UAV decision-making.
- **Computer Vision Pipeline:** Frame preprocessing using OpenCV before running deep learning models.
